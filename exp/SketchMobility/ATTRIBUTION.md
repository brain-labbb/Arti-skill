# Attribution and provenance

Please cite
[Sketch2Arti: Sketch-based Articulation Modeling of CAD Objects](https://arxiv.org/abs/2604.25781),
Yi Yang, Hao Pan, Yijing Cui, Alla Sheffer, and Changjian Li, 2026.

SketchMobility contributions include dataset curation, human motion review,
empty/no-motion labels, corrections to articulation metadata and URDFs, mesh
cleanup, normalization, release identifiers, and documentation.

This is not an unmodified mirror. Original identifiers are retained in each
