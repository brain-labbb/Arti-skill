## 结论先行

方案的 T2–T5 评估轴是有价值且基本可执行的，因为它确实区分出了“源程序铰链意图正确”、“离散状态看似无碰撞”与“严格全行程几何可证”三个不同层次。当前代码在 T3 约束与语义、T4 编辑传播、T5 导出铰链上表现强，但严格连续碰撞和原生物理元数据仍是明显短板。

本轮已执行的部分不是 readiness 清单：T2 现场生成新模板并做隐藏 seed 测试；T3 实际编译 1,188 个资产并做两个独立模型审查；T4 执行 288 组编辑前/后编译；T5 实际运行精确 FCL 碰撞、PyBullet、MuJoCo 和 Genesis。但这些结果不支持“超过 SOTA”的结论：本轮没有运行外部 SOTA baseline，只完成了内部四臂中的新模板生成，且每类别/方法只有一次作者重复。

## T2 — Template + Distribution Reliability

T2 的 24/24 个生成任务已结束；所有并发 run 结束后，已从冻结的
`run_result.json` 重建六类别总汇总，不使用单类别运行期间被覆写的中间 summary。

### 冻结协议

- 类别：6 个真正未见模板类别，按 simple/medium/complex 各 2 个。
- 类别为 `flip_phone`、`clamp_meter_with_hinged_jaw_and_rotary_selector`、`garden_gate`、`air_purifier_with_filter_door`、`folding_kick_scooter`、`extension_ladder`。
- 方法：Naive same-LLM、w/o Source Map、w/o TemplateDesign、Full Ours，同一 `gpt-5.6-sol/high` 作者模型。
- 总数：6 类 × 4 arm × 1 作者重复 = 24 个全新模板。
- 首轮隐藏测试：seed 0–15；最多 3 轮自动修复；最终测试：seed 0–35 + 模板声明的 `TEMPLATE_CORNERS`。
- 作者禁止读取既有 target template、其他 run、隐藏 case 和本 arm 未提供的 SourceMap/TemplateDesign；轨迹审计发现违规则该 run 失效。

### 正式结果

24/24 runs 完成且全部通过协议审计；违规 0，人工干预 0。`Final success`
严格指最后一轮 repair-set seed 0–15 全部通过，不等于后续 all-36 或
all-corners。

| Method | 首轮 executable / saved | First-shot | Final success | All-36 | All-corners | Regression retained | Mean repairs | Mean authoring time |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Naive same-LLM | 5/6 / 6/6 | 4/6 = 66.67% | 6/6 | 6/6 | 6/6 | 75/75 | 0.33 | 903 s |
| w/o Source Map | 5/6 / 6/6 | 1/6 = 16.67% | 6/6 | 5/6 | 4/6 | 54/54 | 1.00 | 2,003 s |
| w/o TemplateDesign | 6/6 / 6/6 | 3/6 = 50.00% | 6/6 | 5/6 | 5/6 | 64/64 | 0.50 | 1,244 s |
| Full Ours | 3/6 / 5/6 | 1/6 = 16.67% | 6/6 | 6/6 | 6/6 | 27/27 | 1.33 | 1,885 s |

总体 first-shot 只有 9/24 = 37.50%，首轮 seed 级通过 220/384 = 57.29%；按
Naive、w/o Source Map、w/o TemplateDesign、Full 分别为 75/96、54/96、64/96、
27/96。自动修复后 24/24 都达到 repair-set final success，但独立扩展测试
只有 22/24 达到 all-36，21/24 达到 all-corners。全部方法合计为
860/864 seed full-QC、291/318 corners 和 220/220 首轮已通过 seed 的 regression
retention。

Corner 数是各新模板自声明的，因此不应只比较 micro rate 而忽略分母：Naive
为 34/34，w/o Source Map 108/134，w/o TemplateDesign 37/38，Full 112/112。
四个分布级失败是：

- `extension_ladder / w/o Source Map`：36/36 seeds，但 corners 5/29；
- `extension_ladder / w/o TemplateDesign`：34/36 seeds，corners 6/6；
- `folding_kick_scooter / w/o TemplateDesign`：36/36 seeds，corners 14/15；
- `garden_gate / w/o Source Map`：34/36 seeds，corners 21/23。

24 个 run 总共使用 19 轮自动修复，累计模型调用墙钟 36,211 s（任务
并发，不是端到端等待时间），记录 190,310,233 input tokens 和 1,464,239 output
tokens。内部 Codex CLI 不提供结算 USD，所以成本为 `N/A`，不伪造估算值。

这一结果不支持 Full Ours 的首轮优势：本次 Full 的 first-shot 与 w/o Source Map
并列最低，平均修复次数最高；它的优点是修复后六个模板都通过 all-36
和自声明 corners。但每格只有一个作者重复，不能把差异归因为稳定的
SourceMap/TemplateDesign 因果效应。当前最可信的结论是：该 T2 协议靠谱，但
Full authoring prompt 本身需要降复杂度并用多重复重新验证。

结果文件：`exp/runtime/t2_formal_v1/authoring/summary.json` 和 `exp/runtime/t2_formal_v1/authoring/runs/*/run_result.json`。

## T5 — Articulation + Collision + Physics

### 铰链导出正确性

33/33 资产重建和 URDF 编译成功，189/189 可动关节在 recall、type 和 parent-child 上全部匹配，33/33 资产的关节图完全一致。Axis 误差均值/最大值为 3.55e-7/2.26e-5°，origin bbox 归一化误差为 8.99e-8/1.18e-6，limit range 归一化误差为 1.19e-7/1.17e-6。

这证明的是 compiler/exporter 对源程序铰链意图的保真度，不是人类对“源程序铰链是否语义最优”的判定。

### 全行程碰撞：离散代理与严格结果

| 协议 | 结果 | 解读 |
|---|---:|---|
| PyBullet 离散单关节 11-state | 2,079/2,079 | 直接 parent-child 排除，无 CCD |
| PyBullet 离散 Sobol | 1,536/1,536 | 离散 multi-joint proxy |
| 离散合计 | 3,615/3,615，33/33 assets | 只能叫 proxy，不能叫连续无碰撞 |
| Exact FCL + adaptive continuous certificate | 12/33 assets = 36.36% | 严格失败封闭主指标 |

严格协议下，32/33 资产在时限内完成，Space Shuttle 超时并计失败。关节级几何有效 111/189 = 58.73%，端点可达 236/378 = 62.43%；12 个资产观测到碰撞，14 个存在未认证区间，其中 6 个同时存在两者，最终 21/33 严格无效或未认证。实验评估了 12,564 个离散状态、1,054 个碰撞状态、28,193 个未认证 pair interval 和 19,953,453 个连续 pair certificate；最大穿透 0.4504 m。因存在碰撞、未认证区间和超时，AOR 按协议不报。

### 物理元数据和多仿真器

原生输出仅 53/244 links = 21.72% 同时具备可用 collision + inertial，只有 9/33 资产完整。为了运行可比仿真，另生成标准化 evaluation copies：对缺失/不可信 inertial 用局部 collision/visual AABB 实心铝块（2700 kg/m³）估计，两个无几何 link 使用 1 mm proxy。这使评估副本达到 244/244 links、33/33 assets，但该先验不是真实材料标注。

| 仿真器 | L1–L5 / target state | 结论 |
|---|---:|---|
| PyBullet | 33/33，945/945 | rest/worst-state 33/33 |
| MuJoCo | 33/33，945/945 | rest/worst-state 33/33 |
| Genesis | parser/dynamics/articulation 33/33，945/945 | collision disabled；不计 strict L5 |
| Isaac Sim | N/E | 未获得用户对 Isaac EULA 的明示同意，未安装/运行 |

Genesis 第一个 multi-contact kernel 编译超过 30 分钟，因此保留真实解析/动力学/铰链执行结果，但 `strict_collision_enabled_l5=0`。当前四仿真器 L5 all-pass 必须报 N/E，不能补成 0 或 100%。

## 对实验方案的审核意见

### 靠谱的部分

1. T2 将首轮成功、修复后成功、all-36、corner 和 regression retention 分开，能防止用修复后成功冒充 first-shot。
2. T3 同时量化约束满足和语义精度/召回，避免用“有 part name”代替语义正确性。
3. T4 的 18×16 传播与 baseline-first 时序是正确的，可区分单 seed 成功和分布级稳定。
4. T5 的 gold-before-compile、离散 proxy 和 strict continuous 分层必须保留；本次的 33/33 与 12/33 差异证明这个设计不是冗余的。

### 达到 paper-grade 还必须补的部分

1. 运行与各评估轴任务兼容的外部 SOTA baseline；当前只能说 internal evaluation/ablation，不能说 SOTA superiority。
2. T2 扩展到方案规划的更大 unseen cohort，并至少做 3 个独立作者重复；当前 6 类、1 repeat 适合正式小规模实验，不足以稳定估计方法方差。
3. T3 加入至少两位人类盲审者和仲裁；当前两模型评审只能是可复现 proxy。
4. 修复 T5 严格几何失败，使用真实材料/密度完成 inertial，解决 Genesis collision kernel，并在明示 EULA 同意后补跑 Isaac Sim。
