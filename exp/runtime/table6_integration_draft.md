**指标与缺失值含义。** `Articulable` 是资产能否作为可动物体载入并驱动；`Joints/Asset` 是描述量；`Native Joint Exposure` 是最终交付格式是否显式保存 joint fields。`Joint Type Accuracy`、`Joint Recall`、`Parent-Child Accuracy`、`Axis/Origin/Limit Valid` 的“accuracy/valid”需要独立冻结 gold 或几何 adjudication；仅有 finite/present fields 时只能单列 metadata proxy。`Joint/Asset Geom. Valid` 还要求 axis-on-moving-part、pivot 与 collision behavior 共同正确，离散 penetration-only sweep 不能直接填正式 accuracy。`Full-Range Collision-Free` 的正式含义是完整连续行程和多关节配置中的非预期自碰撞；PyBullet reset-and-detect 是离散 proxy，不是 CCD。`Generic Range` 是失败指标，越低越好；其他 accuracy/pass rate 越高越好。

`N/A` 表示该指标因表示或证据角色而不适用/无法定义，例如 released URDF 有 0 个 collision elements 时的 collision score；`N/E` 表示指标适用但本轮没有按所需协议执行，例如已有 collision geometry 但没有运行 CCD；`N/R` 表示本应适用但公开实现、产物或精确定义结果未发布。0 collision、metadata presence、URDF load、zero reset error 和 same-source agreement 都不能自动提升为 semantic/physical correctness。
