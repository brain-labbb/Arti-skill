# Text-to-CadQuery baseline provenance

This directory is reserved for the official Text-to-CadQuery implementation and
its isolated runtime metadata. Generated experiment outputs are stored under the
corresponding `exp/runtime/table4_constraints_baselines/text_to_cadquery/`
directory.

The repository source, pinned revision, model revision, licenses, environment,
commands, logs, and artifact hashes are recorded after the official smoke run.
